# 阶段 3 功能全面测试（2026-11-06 ~ 11-07）

按 `third_party/icbsp/undo.md` 阶段 3，在阶段 2 的代码（库改名 ICBSP、目录重排、EventState 默认树、DmMotor 等，分支 `phase2`）上做主机侧单元测试、编译矩阵和实板回归。
实板分两轮换线：第 A 轮电机接在 CAN 上（不跑 CAN 回环），第 B 轮拔掉电机、CAN1 ⇄ CAN2 直连。

## 环境

- 板、UART / RS485 跳线、工具链同 `README.md`；宿主分支 `phase2`，submodule = ICBSP（`third_party/icbsp`）`phase2` 分支。
- 第 A 轮 CAN 上的电机：CAN1 = M3508（ID 1）、DM-J4310P（CAN_ID 0x05 / MST_ID 0x06）；CAN2 = GM6020（ID 1，电流模式）、DM-J4340P（0x02 / 0x12，从 CAN1 换到 CAN2：两个插座线序不同）。输出轴都空载、放置平稳，用户允许中幅转动。
  **J4310 不使能**：它的 CAN_ID 0x05 与 GM6020 的反馈 0x205 低 8 位冲突（达妙只比较帧 ID 低 8 位），用户决定不改 ID。
- 第 B 轮：CAN1 H/L ↔ CAN2 H/L，无终端电阻。
- FreeRTOS 堆 64 KB；HAL 时基 TIM8 优先级 15。全程没有启动 TIM3、没有写 PB1（BMI088 加热电阻），H00 / H99 与监视任务核对全部为 0。
- 构建：Debug（-O0 -g3）与 RelWithDebInfo（-O2 -g），两者都 0 warning。

## 发现并修复的问题

| # | 问题 | 处理 |
| --- | --- | --- |
| 1 | **BMI088 `init()` 偶发 IO_ERROR**（库）：P04 连续 200 次 `init()`，第 A 轮 Debug 与第 B 轮第一次 Debug 各 48 次失败，失败行都在加速度计软复位后重读 `ACC_CHIP_ID` 处（`device_bmi088.cpp:162`）。`delay_ms(1)` 在调度器启动后调用 `vTaskDelay(1)`，只等到下一个 tick 边界，实际可能远不到 1 ms，不满足“软复位后 1 ms 才能切回 SPI” | `DeviceBmi088::delay_ms()` 改成 `vTaskDelay(pdMS_TO_TICKS(ms) + 1)`，至少等满（库 `ad1259b`）。之后 Debug / -O2 都 0 次失败，单次 `init()` 93 → 108 ms。另加 `get_init_fail_count()` / `get_init_fail_line()` 诊断（库 `255250b`） |
| 2 | **CAN 组整组没编进去**（测试代码）：`test_can.cpp` 在包含配置之前写了 `#if ... && !ICBSP_CAN_RX_ENABLE`，宏未定义按 0 算，正常构建只编进 C12，C00~C11 全缺（第 A 轮 CAN 组是关的，没暴露；Flash 232660 → 246264 B 才发现） | 文件开头先包含 `service/system/config_check.hpp`，宏未定义 `#error`；其他测试文件核对过没有同样写法 |
| 3 | C11 新判据取初值太晚（测试代码）：CAN2 离线后 CAN1 重发十几次（< 1 ms）就进了错误被动，初值在 40 ms 的离线发送之后才取，增量为 0 | 初值挪到 CAN2 离线之前；-O2 上 `v[8] = 0x10001`（警告 / 被动各 1 次）通过 |
| 4 | GM6020 / J4340P 第一次转动用例失败（M08 超速中止、M09 速度跟不上）：6020 增益过大；4340 减速箱摩擦大 | 重新调参：6020 PID(15, 0.3, 0, 3000, 0, 2000)；4340 阻尼段 Kd = 3、位置段 Kp = 20 / Kd = 1 |

### SPI / BMI088 的“不合理帧”

P01 / P02 / P05 把 |acc| 不在 7~12 m/s² 的帧判为不合理。各轮的不合理帧都能归到机械原因，SPI 层面 0 错误（`errors = 0`、芯片 ID 复核 0 错）：

- 第 A 轮 Debug：成对或成簇出现，加速度最大 39 m/s²，角速度同时变大（板子被碰）。-O2：5 帧，静止孤立帧 0。
- 第 B 轮 Debug P02：1 帧静止孤立帧，z 从 9.95 跳到 12.3 m/s²，三轴同时变化、角速度近 0；时间线被 P05 覆盖，不能完全排除读错，但数值是物理量级、不是全 0 / 全 1 / 字节错位。
- 第 B 轮 -O2 P01：24 帧，其中 15 帧被判成“静止孤立”。它们集中在 6 个时刻（约 402 / 409 / 444 / 450 / 832 / 841 s），每次几毫秒内连续几帧在 5.7 与 14.6 m/s² 之间高低交替，前一帧本身也偏离 9.8，角速度都很小——是平动振动（时间上与用户回到桌边操作吻合），不是读错。
- 测试的“静止”判据只看 |gyro| < 0.2 rad/s，挡不住平动振动；真正的读错应是单帧非物理值、前后帧都正常。今后要更准地区分，可再加“前后帧 |acc| 都在 9.8 ± 0.3”的条件。
