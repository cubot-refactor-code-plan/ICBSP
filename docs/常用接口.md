## UART

```cpp
BspUartT<uart_mode::dma, 128, 128>   // DMA 收发
BspUartT<uart_mode::it, 128, 32>     // 中断收发
```

收发方向：

```cpp
UartDir::RxOnly
UartDir::TxOnly
UartDir::TxRx
```

- DMA 模式的实例必须放在 `.dma_buffer` 段：声明前加 `ICBSP_DMA_BUFFER(变量名)`（`bsp_dma_buffer.hpp`，展开成 `section(".dma_buffer.<变量名>")`，段名按变量唯一）
- `BspUartT` 只有头文件，缓冲区大小随便改，不用补显式实例化；实例必须写进 `board_instances.hpp` 的 `BSP_UART_INSTANCES`（`init()` 会核对）
- 调试打印走 `board_cfg.hpp` 里的 `print_uart(...)`，等价于 `bsp_uart1.printf(...)`（宿主自己的宏，库不引用；`sys_task` 的耗时报告用 `system_set_report_hook()` 接）

## CAN

```cpp
BspCanT<16, 16> bsp_can1(
    {.hfdcan = &hfdcan1,
     .name = "CAN1"});
```

```cpp
uint8_t d[8] = {...};
bsp_can1.send(0x200, d);                             // 标准帧 8 字节
bsp_can1.send(0x1ABCDE, d, 4U, FDCAN_EXTENDED_ID);   // 扩展帧 4 字节
```

`CanRxNodeT<CanT>` / `CanTxNodeT<CanT>` 负责按 ID 分发与槽位聚合，一般由 `DjiMotor` 等设备内部使用；
接收节点默认只收 8 字节帧，注册时传 `CAN_DLC_MASK_ANY` 可以收短帧。
没有节点认领的帧进回退缓冲（深度 `CAN_RX_RETURN_FRAMES`，0 = 不保留），可以通过 `bsp_can1.receive()` 自己取；`send()` 只能在任务里调用。

## DJI 电机

```cpp
DjiMotor<Motor3508, decltype(bsp_can1)> chassis_lf(bsp_can1, 1U);
ICBSP_CHECK(chassis_lf.init() == Status::OK);
```

`DjiMotor` 按单个电机创建；`dji_motor_group` 没有并入库，多电机自己建多个实例。

## 直流电机 + PID 波形

`DeviceMotor` 不绑定串口，`pid_frame()` 只负责组 JustFloat 帧：

```cpp
DeviceMotor motor({.pwm_a = &bsp_pwm1, .pwm_b = &bsp_pwm2, .encoder = &bsp_encoder1, ...});
ICBSP_CHECK(motor.init() == Status::OK);

uint8_t frame[16];
const size_t n = motor.pid_frame(
    frame,
    DeviceMotor::PID_TARGET | DeviceMotor::PID_OUTPUT);

bsp_uart1.send(frame, n, 0);   // App 层自己发
```

可选字段：

```cpp
DeviceMotor::PID_TARGET
DeviceMotor::PID_FEEDBACK
DeviceMotor::PID_OUTPUT
DeviceMotor::PID_ALL        // 默认
```

帧格式：`float... + 00 00 80 7F`，函数返回实际字节数。

## 姿态 PID

```cpp
#include "quaternion_pid.hpp"

QuaternionPID attitude(cfg);
Vector3 omega_ref = attitude.calc(q_ref, q, gyro);
```

标量 PID 仍然只包含 `pid.hpp` 即可，不需要 `quaternion_pid.hpp`。

## 系统状态

```cpp
extern EventState sys_state;

sys_state.wait_running();               // 业务任务入口先等运行态
sys_state.error(Status::TIMEOUT);       // 运行期错误，向上传播
sys_state.init_error(Status::IO_ERROR); // 初始化失败
```

`set_parent()` 可把子系统挂到父状态上：错误只向上传播，不聚合 `running`。
